# Journey OptimizerのCX Enterprise Coworker

Coworkerは、Adobeの会話型AIであり、Adobe Journey OptimizerなどのCX Enterpriseアプリケーションと統合されています。 Adobeのベストプラクティスを適用して、効率的かつ正確に作業できます。 タスクをわかりやすい言葉で説明してください。 サインアップ後にメールでウェルカムジャーニーをリクエストし、3日後にフォローアップすることができます。 または、「このアップロードされたフローチャート画像からジャーニーを構築する」と依頼し、Coworkerが作業を計画します。 接続されているAdobe アプリケーション全体でタスクを実行し、レビューの結果を表示します。

Journey Optimizerにより、カスタマージャーニーのステップを構成したり、シミュレーションを準備したり、ロイヤルティに関する課題を設定したりするのに費やす時間を削減し、関係者が制作したものをレビューおよび承認するために費やす時間を増やすことができます。 Adobe Workfrontでは、プランニング、実行、フォロースルーを担当者が担当しますが、あらゆるステップで顧客自身が管理することができます。

## 共同作業を始める

Adobe Workfrontを初めて利用する場合は、 Journey Optimizerやその他のCX Enterpriseアプリケーションにおいて、作業効率を向上させる方法について包括的に解説します。
