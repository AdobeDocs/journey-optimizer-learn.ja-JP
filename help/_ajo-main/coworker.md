# Journey Optimizer の CX Enterprise Coworker

Coworker は、アドビの対話型 AI で、Adobe Journey Optimizer などの CX Enterprise アプリケーションと統合されています。これにより、効率的で正確な作業に役立つアドビのベストプラクティスを適用できます。タスクを平易な言語で説明します。新規登録後にメールでウェルカムジャーニーを、3 日後にフォローアップをリクエストできます。 または、「このアップロードされたフローチャート画像からジャーニーを作成してください」と依頼すると、Coworker で作業を計画できます。これにより、接続されているアドビアプリケーション全体でタスクを実行し、その結果をレビュー用に表示できます。

Journey Optimizer では、これは、ジャーニーの各ステップの設定、シミュレーションの準備、ロイヤリティの課題の設定に費やす時間が削減し、Coworker で作成した内容のレビューや承認に費やす時間が増加したことを意味します。Coworker でプランニング、実行、フォロースルーを処理する間、すべてのステップでコントロールを維持できます。

## Coworker の基本を学ぶ

Coworker を初めて使用しますか？ここから開始して、Journey Optimizer やその他の CX Enterprise アプリケーション内でより効率的に作業に役立つ仕組みを包括的に理解してください。
