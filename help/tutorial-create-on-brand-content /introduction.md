# AIを活用してブランドに即したメールコンテンツを作成

Adobe Journey OptimizerのAIを利用して、ブランドに即したメールコンテンツを大規模に制作する方法をご紹介します。 このチュートリアルでは、ブランドガイドラインと参照コンテンツを使用して生成をガイドし、生成モデルを選択し、AI生成のテキストと画像をテンプレートに直接挿入しながら、単一のプロンプトから生成されたメール全体を示します。 また、同じブランドアセットを利用して、自動化された品質チェックを実施し、各バリエーションのコンプライアンス、トーン、ブランドの整合性をスコアリングすることもできます。
