# Journey Optimizerでのブランドに即したコンテンツの制作

Adobe Journey OptimizerのAIを利用して、カスタマージャーニー全体でブランドに即したコンテンツを制作、調整、拡張する方法を解説します。

このコースでは、ブランドガイドラインの作成と設定から、包括的なキャンペーンの生成、個々のコンテンツコンポーネントの編集、ビジュアルの強化、多言語体験の実現に至るまで、あらゆる取り組みを順を追って解説します。また、自動化された品質チェックを適用し、ブランドの整合性を確保し、あらゆるコミュニケーションでガバナンスを維持する方法についても解説します。 最終的には、コンテンツ制作を合理化し、一貫性を向上させ、チャネル全体でパーソナライズされた高品質な体験を提供できるようになります。
