# 多言語バージョンのコンテンツを作成および調整

このステップでは、ロケールの例としてスペイン語とフランス語を使用して、Adobe Journey Optimizerを使用してメッセージを他の言語に翻訳および適応させます。 既存のタッチポイントをロケールテンプレートにコピーし、AIを利用して、ブランドに即した翻訳を他の手動または自動翻訳ワークフローと並行して生成します。 スコアリングを確認し、トーンとメッセージを調整して、翻訳されたコンテンツをブランドガイドラインに沿ったものにします。
