# 多言語バージョンのコンテンツを作成および調整

ブランドの一貫性を維持しながら、複数の言語に合わせてコンテンツを翻訳および調整する方法をご確認ください。 この概要では、多言語バージョンのキャンペーンの作成、AIを活用した翻訳によりローカライズされたコンテンツの迅速な生成、ブランドガイドラインに沿ったトーンやメッセージの微調整などを行う方法を説明します。 また、自動化されたワークフローと即座に翻訳を組み合わせて、チャネルをまたいでグローバルなコミュニケーションを効率的に拡張する方法も紹介します。
