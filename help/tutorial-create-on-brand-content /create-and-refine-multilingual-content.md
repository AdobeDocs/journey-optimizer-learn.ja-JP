# AIを活用して多言語コンテンツを強化

ブランドの一貫性を維持しながら、複数の言語に合わせてコンテンツを翻訳および調整する方法をご確認ください。 この概要では、多言語バージョンのキャンペーンを作成し、AIによる翻訳を使用してローカライズされたコンテンツを迅速に生成する方法を説明します。 また、ブランドガイドラインに合わせてトーンやメッセージを最適化する方法や、自動化されたワークフローと現場での翻訳を組み合わせて、チャネルをまたいでグローバルなコミュニケーションを効率的に拡張する方法も解説します。
