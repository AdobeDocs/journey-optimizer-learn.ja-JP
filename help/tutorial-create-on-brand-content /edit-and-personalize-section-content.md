# セクションコンテンツの編集とパーソナライズ

AIを活用して、コンテンツの個々のセクションを改善したり、パーソナライズしたりする方法を解説します。 このビデオでは、ブランドの一貫性を維持しながら、既存のテンプレート内の件名、プリヘッダー、テキストブロック、画像を編集する方法を説明します。 ブランドガイドラインを使用しながら、プロンプトの適用、参照コンテンツの活用、トーンとメッセージの調整、新しいビジュアルの生成方法などを検討し、コミュニケーションのあらゆるコンポーネントをまたいで、高品質でコンプライアンスに準拠した結果を実現します。
