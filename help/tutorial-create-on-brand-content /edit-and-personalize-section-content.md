# AI アシスタントでセクションコンテンツを編集し、パーソナライズ

AI アシスタントを使用して、コンテンツの個々のセクションを改善したり、パーソナライズしたりする方法を説明します。 このビデオでは、ブランドの一貫性を維持しながら、既存のテンプレート内の件名、プリヘッダー、テキストブロック、画像を編集する方法を説明します。 プロンプトの適用、参照コンテンツの活用、トーン、メッセージ、ビジュアルの調整について解説します。 ブランドのガイドラインを遵守しながら、コミュニケーションのあらゆる要素で一貫性のある質の高い成果を上げることができます。
