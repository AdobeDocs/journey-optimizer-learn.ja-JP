# Adobe Journey Optimizerでのブランドの設定

Adobe Journey Optimizerのブランドガイドラインを設定して、あらゆるチャネルで一貫性のあるブランドに即したコミュニケーションを行う方法を説明します。 このガイドでは、ブランドドキュメントをアップロードし、スタイル、ビジュアル、IDの詳細など、主要なブランド要素を構造化する方法を解説します。 また、これらのガイドラインを改善してコンテンツ生成を強化し、品質チェックを自動化する方法も紹介します。これにより、ブランドアイデンティティを強力かつ効果的に維持できます。 ステップバイステップのチュートリアルについては、次の動画をご覧ください。
