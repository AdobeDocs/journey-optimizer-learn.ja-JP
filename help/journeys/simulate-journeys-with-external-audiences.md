# 外部オーディエンスを使用したジャーニーのシミュレーション

{{limited-availability}}

チケット IDや旅行日など、プロファイルに保存されていない属性を含む、CSV ファイルまたはフェデレーションオーディエンス構成から外部オーディエンスプロファイルを使用するジャーニーをシミュレートする方法について説明します。 このビデオでは、オーディエンスのフィルタリング、外部属性を使用したメッセージのパーソナライズ、シミュレートされたユーザーの作成、オーディエンスデータのモック処理などを通じて、ジャーニーを公開する前に適切なパスを検証します。
